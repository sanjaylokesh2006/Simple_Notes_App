# API Documentation

## Generated Endpoints

The following endpoints are generated automatically by the AI Software Engineering Platform.


### Create Note

**Endpoint**

POST /create-note

**Description**

Users can create new notes with a title and content.


### Read Note

**Endpoint**

POST /read-note

**Description**

Users can view the details of an existing note.


### Update Note

**Endpoint**

POST /update-note

**Description**

Users can modify the title or content of an existing note.


### Delete Note

**Endpoint**

POST /delete-note

**Description**

Users can remove an existing note.


### Search Notes

**Endpoint**

POST /search-notes

**Description**

Users can search for notes by title or content.
